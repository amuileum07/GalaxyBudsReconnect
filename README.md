# GalaxyBudsReconnect

Linux에서 Flatpak으로 설치한 **Galaxy Buds Manager (Galaxy Buds Client)**의 꼬인 연결 상태를 정리하고 다시 연결하는 도구입니다. 추가 Python 패키지는 필요하지 않습니다.

## 실행

프로젝트 폴더에서 터미널을 열고 다음 명령을 실행하세요. `sudo`는 사용하지 마세요.

```sh
python3 reconnect.py
```

이어폰을 케이스에서 꺼내거나 케이스 뚜껑을 연 상태로 실행하세요. 연결을 다시 만들기 때문에 정상 연결 중에도 해당 이어폰의 소리가 잠시 끊깁니다.

변경 없이 실제 연결 상태와 앱 실행 개수만 확인하려면:

```sh
python3 reconnect.py --check
```

## 복구 순서

1. 앱 설정에서 최근 사용한 이어폰 주소를 읽고 주소 형식, 기존 페어링, 어댑터 상태를 확인합니다.
2. 동일 도구의 동시 복구를 막고, 실행 중인 Galaxy Buds Manager 인스턴스를 모두 종료합니다.
3. 해당 이어폰의 남아 있는 연결 요청을 해제하고 다시 연결합니다.
4. 시스템의 `Connected: yes` 응답으로 연결 여부를 검증합니다.
5. 실패하거나 중단해도 앱을 다시 실행합니다. 앱 실행 자체에 실패하면 오류를 표시합니다.

페어링 정보, 앱 설정, 배터리 기록을 삭제하지 않습니다. 다른 블루투스 장치를 끊거나 블루투스 서비스를 재시작하지 않습니다. 자동으로 반복 실행하는 예약 작업은 설치하지 않습니다.

## 실패할 때

Buds3 Pro 양쪽을 케이스에 넣고 뚜껑을 연 상태에서 아래 연결 버튼을 3초 이상 눌러 페어링 모드로 전환한 뒤 다시 실행하세요. [삼성 공식 안내](https://www.samsung.com/uk/support/mobile-devices/how-to-connect-galaxy-buds-to-a-smartphone/)

이어폰 전원, 거리, 다른 기기와의 연결, OS 또는 이어폰 펌웨어 문제까지 자동으로 고칠 수는 없습니다. 시스템 연결 성공은 소리 재생이나 앱 화면의 정상 동작까지 보장하지 않으므로 마지막에 재생을 확인하세요.

다른 장치를 지정하려면 `--mac AA:BB:CC:DD:EE:FF`을 붙이세요. 지정한 장치도 기존에 페어링되어 있어야 합니다.

실행 결과 코드: `0` 상태 확인/복구 성공, `1` 오류, `130` 사용자 중단.

## 검증

```sh
cd GalaxyBudsReconnect
python3 -m unittest -v
```

검증은 모의 명령 응답을 사용하며 실제 블루투스 연결을 변경하지 않습니다.
